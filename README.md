# 🇮🇷 مترجم زیرنویس یوتیوب به فارسی

> ترجمه **کاملاً آفلاین** زیرنویس‌های یوتیوب به فارسی، با استفاده از هوش مصنوعی محلی — بدون ارسال داده به هیچ سرور خارجی

---

## ✨ ویژگی‌ها

- 🔒 **کاملاً آفلاین** — هیچ داده‌ای به اینترنت ارسال نمی‌شود
- ⚡ **ترجمه پیش‌از‌موعد** — کپشن‌ها پشت صحنه ترجمه می‌شوند، نتیجه فوری است
- ⏸️ **نمایش هوشمند** — با Pause کردن ویدیو، ترجمه‌های آماده یکی‌یکی نشون داده می‌شن
- 🖱️ **ماندگاری با Hover** — موس را روی متن نگه دارید تا ناپدید نشود
- 🔄 **دو حالت ترجمه**: Live (بلادرنگ) و Pre-fetch (از فایل زیرنویس)
- 💾 **کش هوشمند** — جملات تکراری دوباره ترجمه نمی‌شوند
- 📥 **دانلود VTT** — خروجی زیرنویس فارسی به فرمت VTT

---

## 📋 پیش‌نیازها

### ۱. نصب Ollama

**Ollama** یک ابزار رایگان برای اجرای مدل‌های هوش مصنوعی روی کامپیوتر شماست.

🔗 دانلود از: [ollama.com](https://ollama.com)

پس از نصب، یک مدل دانلود کنید. **پیشنهاد برای فارسی:**

```bash
ollama pull aya-expanse:8b
```

> 💡 اگر RAM کمتری دارید، از مدل سبک‌تر استفاده کنید:
> ```bash
> ollama pull qwen2.5:3b
> ```

| مدل | حجم | کیفیت فارسی | سرعت |
|-----|-----|-------------|------|
| `aya-expanse:8b` | ~5GB | ⭐⭐⭐⭐⭐ | متوسط |
| `qwen2.5:7b` | ~4.5GB | ⭐⭐⭐⭐ | متوسط |
| `qwen2.5:3b` | ~2GB | ⭐⭐⭐ | سریع |
| `llama3.1:8b` | ~5GB | ⭐⭐⭐⭐ | متوسط |
| `gemma2:2b` | ~1.5GB | ⭐⭐ | سریع‌ترین |

### ۲. اطمینان از اجرای Ollama

Ollama باید در پس‌زمینه در حال اجرا باشد. برای تست:

```bash
ollama serve
```

یا کافیه برنامه Ollama را اجرا کنید — در ویندوز در System Tray ظاهر می‌شود.

## 🎬 نحوه استفاده

### قدم اول — باز کردن یوتیوب

یک ویدیو با **زیرنویس (CC)** باز کنید و زیرنویس را **فعال** کنید.

> ⚠️ برای حالت Live، زیرنویس باید در یوتیوب روشن باشد (دکمه CC).

### قدم دوم — ترجمه خودکار شروع می‌شود

افزونه بدون نیاز به کلیک اضافه، خودکار شروع به کار می‌کند.

### قدم سوم — دیدن ترجمه‌ها

| عمل | نتیجه |
|-----|-------|
| ▶️ **پخش ویدیو** | افزونه کپشن‌ها را پشت صحنه ترجمه می‌کند |
| ⏸️ **Pause** | ترجمه‌های آماده یکی‌یکی نمایش داده می‌شوند |
| 🖱️ **Hover روی متن** | متن تا زمانی که موس روی آن باشد ناپدید نمی‌شود |
| ▶️ **Resume** | بافر پاک شده، دوباره شروع به جمع‌آوری می‌کند |

## 🔧 عیب‌یابی

### ❌ ترجمه نشان داده نمی‌شود

1. مطمئن شوید **Ollama در حال اجرا** است: آدرس `http://localhost:11434` را در مرورگر باز کنید
2. مطمئن شوید **مدل دانلود شده**: `ollama list` را در terminal اجرا کنید
3. زیرنویس یوتیوب را **روشن** کنید (دکمه CC در پلیر)
4. افزونه را **Reload** کنید: `chrome://extensions` → دکمه 🔄

### ❌ خطای "Extension context invalidated"

صفحه را **F5** کنید. این خطا زمانی رخ می‌دهد که افزونه Reload شده باشد.

### ❌ ترجمه کند است

- از مدل سبک‌تر استفاده کنید: `qwen2.5:3b` یا `gemma2:2b`
- مطمئن شوید برنامه‌های سنگین دیگر باز نباشند
- اگر GPU دارید، Ollama به‌صورت خودکار از آن استفاده می‌کند

### ❌ ترجمه فارسی نیست یا اشتباه است

مطمئن شوید مدل انتخاب‌شده از فارسی پشتیبانی می‌کند. بهترین انتخاب:
```bash
ollama pull aya-expanse:8b
```
